#### ✦ Mesin Absensi Pintar & Microcontroller Engineering
Bukan simulasi software semata — merancang PCB/skematik, menyolder komponen fisik, dan menulis firmware berkinerja tinggi dari *scratch*:

- ✧ **Mesin Absensi RFID ESP32 High-Speed (IoT Multi-User):**
  - **FreeRTOS Dual-Core Non-Blocking Queue:** Pemisahan tugas (*Core 1 ke Core 0*), menjamin pembacaan kartu instan tanpa jeda antrean bagi banyak pengguna.
  - **Antenna Gain Tuning (48dB RxGain):** Modulasi 100% ASK dengan deteksi agresif *PICC_WakeupA* agar kartu terbaca sensitif dari berbagai sudut.
  - **3-Layer Offline Fallback:** Sinkronisasi online via HTTP/WebSocket; jika koneksi terputus, data otomatis disimpan ke MicroSD Card dan NVS Internal Flash tanpa resiko data hilang.
  - **Hardware RTC DS1302 & NTP Sync:** Waktu presisi WIB (UTC+7) terkalibrasi otomatis via Network Time Protocol.
- ✧ **Display & Visual Sensor Interfaces:**
  - Pemrograman layar **OLED SSD1306 (I2C/SPI)** dengan animasi visual lirik/data (`LoveMeNot_OLED`) dan **LCD 16x2/20x4**.
  - Monitoring level tangki air pintar (*Smart Tank IoT*) dan integrasi sensor ultrasonik.
