## Proyek

**Sempoa SIP TC Pariaman** — [sempoasippariaman.com](https://sempoasippariaman.com/)
Sistem manajemen tutoring center yang sudah live: data murid, histori absensi, dashboard. Deploy pakai Docker Compose + Nginx di Linux VPS.

**Mesin absensi RFID (ESP32)**
Firmware ESP32 dengan FreeRTOS dual-core. Baca kartu RC522, sinkron via HTTP/WebSocket, fallback offline ke MicroSD dan NVS, waktu dari RTC DS1302 + NTP. Dipakai di Sempoa SIP.

**[web_pondok_titis](https://github.com/sultaniqalbi/web_pondok_titis)**
Sistem manajemen indekos: monitoring kamar, pembukuan, hak akses. Masih dikembangkan.
